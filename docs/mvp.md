# MVP Definition

## MVP Goal

Validate whether users find value in adding rental options and receiving a personalized ranking that helps them make a decision.

## Primary Workflow

1. User creates a search.
2. User adds rental options manually.
3. User selects priorities.
4. App calculates ranking.
5. User reviews recommendation and decides what to contact, visit, discard, or favorite.

## Core Screens

### 1. Search Setup

User defines:

- City or area.
- Rental type: room, studio, flat, coliving, other.
- Budget.
- Ideal move-in date.
- Main destination for commute: work, university, or custom.

### 2. Rental List

Shows saved options with status:

- New
- Contacted
- Visit planned
- Visited
- Favorite
- Discarded

### 3. Add Rental

Fields for MVP:

- Title
- Listing URL
- Price
- Bills included
- Deposit
- Agency fee
- Location
- Commute time
- Room or home size
- Furnished
- Private/shared bathroom
- Contract available
- Available date
- Notes
- Photos, optional later

### 4. Priorities

User chooses importance for:

- Price
- Total move-in cost
- Commute
- Location
- Contract/security
- Room quality
- Privacy
- Bills included
- Availability
- Personal feeling

### 5. Comparison

Shows:

- Best overall
- Best value
- Cheapest
- Lowest risk
- Fastest commute
- Risky options

### 6. Rental Detail

Includes:

- Score breakdown
- Pros
- Cons
- Risk signals
- User notes
- Visit checklist

## Non-Goals For MVP

- Marketplace supply.
- Owner accounts.
- Payments or booking.
- Complex scraping.
- Legal verification service.
- Full map search.
- AI automation before the manual workflow feels useful.

## Success Metrics

- User adds at least 3 rentals.
- User compares at least 2 times.
- User marks a favorite or discards an option.
- User returns after a visit to update notes.
- User says the ranking helped them decide or reduced uncertainty.
